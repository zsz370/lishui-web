# 首页设计对比样板

状态：仅本地开发预览，未部署、未推送。正式首页保持现有视觉。

入口：http://127.0.0.1:5173/design-preview 。通过顶部按钮切换现有设计与改进样板；“手机预览”在真实约390像素的 iframe 中显示完整页面。启动方式：`npm run dev:web`。

## 审视与取舍

现有品牌为绿色、纸色底、溧字标记和淮源姐，页面包含目的地、线路、文化、问答、出行准备与收藏。现有真实照片、内容分类和交互有价值，全部保留。现有首屏浅色遮罩较重，照片的自然色彩被冲淡；标题与内容层级较接近；发现区主图存在提升空间；出行准备横向标签占用较多空间。

样板采用保护性调整：绿色品牌不变，中文宋体用于目的地与文化标题（与当地历史文化主题相关），正文保留现有无衬线字体；首屏改为暗色照片遮罩与浅色文字，保留相同的提问、三张风景渐变、暂停、动态人物与字幕/语音；放大主图、统一4像素图片/按钮边角、增加章节间距；出行准备在桌面采用左侧分类、右侧答案，手机仍为三列分类。

视觉变化7/10，动效4/10，信息密度3/10。采用原生CSS，使用项目现有Phosphor图标与真实素材，无新增依赖、无模拟景点图片。

## 隔离与验证

样板路由受 `import.meta.env.DEV` 控制；样板CSS全部限定于 `.sample-modern` 或样板工具栏。生产构建中没有 DesignPreview 模块、样板路由和样板CSS。原有路由、导航、审核数据、接口、线上部署目录与密钥没有更改。

构建检查使用独立输出 `.web_review/design-study-build`，没有覆盖原 `dist`。`npm run build -- --outDir .web_review/design-study-build` 通过。首页内容、单导游和已有可用性回归共21项通过。

浏览器检查：桌面1280像素无横向溢出；手机iframe实际389像素无横向溢出，发现区变为单列，标题46像素；现有设计和样板切换保留输入草稿、探索主题与线路选择。此为浏览器尺寸模拟，不等同于真实手机验收。浏览器viewport能力未改变当前标签尺寸，因此以iframe验证窄屏。
