# 遇见美溧整站 UI 本地改版

本批扩大到整站：主页、发现溧水、地点详情、风物图鉴、导览对话、我的行程、旅途服务、文化体验、关于作品，共九个页面类型。仅本地预览，未上传、未推送、未部署。

入口：http://127.0.0.1:5173/design-preview 。顶部可切换现有/新版设计、选择页面、查看约390像素手机预览。普通站内导航也保持当前视觉版本。

## 审视结果与修改

此前问题是各页缺少共同的视觉规则：不同字号、底色、边角和信息密度混用；导览页在窄屏中被欢迎、历史提示与人物区占据；行程页的主题草案先于核心输入占据过多空间；图鉴和详情的重复导航导致内容下移。

统一采用松绿文字、近白底与雾绿辅助区；统一按钮、输入边界、页面宽度、图片边角与焦点样式。景观与文化阅读使用中文宋体，聊天和行程工具保留易读的无衬线标题。沿用项目照片和既有Phosphor图标，无新增依赖、无虚构地方素材。

| 页面 | 调整 |
| --- | --- |
| 首页 | 沿用前批风景样板，并应用新的全站导航、背景、页宽和页脚。 |
| 发现 | 主景观大图与其他栏目组合；统一主题筛选、搜索与地点目录。 |
| 详情 | 地点名称先于大图；文章与紧凑导览邀请分栏，窄屏改为单列。 |

| 导览 | 上次规划提示默认收起；桌面输入框位于可见区域，窄屏输入框固定在底部导航上方；键盘展开沿用原有逻辑。 |
| 行程 | 可选主题草案收进展开区；统一条件表单、地点编排和费用核对的层级与边界。 |
| 服务 | 统一分类入口、阅读与表单区域，保留加载、失败和咨询入口。 |
| 文化 | 以既有骆山大龙资料照片替代原图形展示，统一答题与反馈排版。 |
| 关于 | 统一图片、阅读与制作说明层级，保留数据使用及来源说明。 |

## 参考依据

用户提供的乌镇官网：http://www.wuzhen.com.cn/ ；Awwwards栏目：https://www.awwwards.com/websites/sites_of_the_day/ 。乌镇的目的地体验和服务组织、Awwwards案例的大图与排版对比作为方向；设计最终适配溧水内容与导览任务。

两个指定实时页面直接读取仍超时；此前乌镇浏览器还出现证书错误，未绕过检查。可读取依据为官网搜索缓存中的住宿分类内容（https://www.wuzhen.com.cn/web/vacation?id=3）及Awwwards栏目/案例搜索缩略图（如 https://www.awwwards.com/sites/waldhaus-sils）。本批没有宣称完整复现实时页面的视觉或交互，也没有把Awwwards获奖作品等同于主流网站的统一标准。

## 隔离

新样式位于 `src/styles/WholeSiteDesign.css`，作用范围为 `.app-shell.travel-redesign`；首页沿用前批限定于 `.sample-modern` 的规则。开发环境中启用整站设计上下文和对比工具，切换为现有设计时取消新作用域。

生产构建默认关闭新版视觉；构建中无整站新CSS和对比工具模块。已在独立本地生产预览中核对：根类名为 `app-shell`，无对比工具，首页标题仍为现有设计。独立输出 `.web_review/whole-site-design-build`，没有覆盖原 `dist`，没有操作远程服务器或域名。

页面路由、已审事实、问答正文、存储规则、导览身份与后台接口未改。上次规划与主题草案的原操作保留在展开区；原样式对照下仍按原布局展示。
