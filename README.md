## 3. 首页迎宾实验版（2026-10-02）

- 顶部导航沿用原框架；首屏使用溧水风景素材、导览入口和淮源姐欢迎区。
- 首次进入展示三段欢迎字幕，支持重播字幕和点击播报；当前形象使用淮源姐最新定稿静态图，同形象 GIF 后续接入。
- 浏览器原生中文语音用于实验，支持情况和音色取决于设备；正式版可换成统一配音。
- 电脑端三处风景可手动切换；首页提供四个栏目入口与一段旅程推荐，避免逐项平铺。
- 风景、角色图、GIF 和静态兜底图都已放入 `public/`，构建后不依赖工作区外的素材目录。
- 手机端使用底部“首页 / 探索 / 行程 / 说明”导航，内容单列阅读。
- 探索按“栏目 → 主题 → 详情”展开；搜索可查找未在首页展示的记录。
- 页脚和说明页使用欢迎与导览文案，不展示团队规模、原创知识库或大赛关系。
- 行程使用本机存储，刷新后保留；复制不可用时支持手动复制。
- 十二位角色采用定稿或最高版本；“认识导游”按职责分组，栏目与详情提供相应角色入口，聊天使用对应头像。
- 首页、探索总览与行程页可进入“旅途服务”：天气、住宿、交通、礼仪双语、求助退改、同行关怀、伴手礼与行程咨询。地点问答也能按需求转接角色。
- 天气通过和风服务端代理获取；住宿可按日期查询飞猪平台报价与详情，未返回的房型库存和政策仍须确认。
- 记录见 `docs/首页迎宾设计与推进记录_2026-10-02.md` 和 `docs/栏目化与移动体验推进记录_2026-10-02.md`。

## 4. 素材怎么替换

服务线职责、知识库清理与后续接线见 `docs/服务线知识库与产品流程_2026-10-02.md`。当前问答包含固定已审QA、共享向量检索、联网待核补充和工具协作。默认天气走服务端；只有显式设置 VITE_AGENT_API_ENABLED=false 时才启用公开天气与本地规则演示。前端不要放入任何服务密钥。

## 8. 角色与接口盘点

```bash

```

第一条复核原始文件哈希、统计角色知识并输出十二份获审QA分包；第二条仅检查接口配置。加`--live`才会发起真实烟测请求。结果位于`docs/agent-audit/`。配置样例为`config/integrations.env.example`；本机密钥文件`config/integrations.env.local`已被Git忽略，任何密钥都不要设置`VITE_`前缀或放入`public/`。

config/agent-system.plan.js 已作为前后端共用角色与栏目职责注册表。服务端按任务分工、处理依赖、汇总与翻译，网页显示伙伴头像和处理状态。栏目统筹目前采用规则调度，后续再扩大模型自主规划范围。

## 9. 本地运行与验收

```bash

```

API 绑定 127.0.0.1:8787；前端端口5173，预览端口4173，均代理 /api。生产部署须让同源网关把 /api 转发到后端，静态 dist 单独上线无法提供真实查询。

```bash
npm run test:qa
npm run test:agents
npm run test:foundation
npm run build
npm run check:integrations
node scripts/check-agent-flows.mjs
npm run check:foundation
```

三个test命令离线；check:integrations、check-agent-flows及check:foundation发起真实只读请求。更新语料后执行knowledge:export与rag:index，再重启API，避免使用旧进程中的索引。健康检查 /health、索引就绪 /ready、角色注册表 /api/agents。原始资料未全部获审，联网摘录不会自动进入正式知识库；已审事实保留原文，模型参与资料选择和统筹建议。


## 10. 一日结构化行程（2026-10-04）

打开 `/itinerary`，或从首页选择两条任务草案。先填日期、起终点、同行人数、交通和预算；每个地点点击“查地点”并从候选中选用实际入口/店铺/展馆，再填自己的停留和费用估计，点击“查询路线并重算时间”。时间冲突、超预算、交通未知和未核开放条件会列在核对区。移动/移除或更换交通后按需重新查询；超过24小时的估时不参与计算。地图不保证出行日班次或预约。

行程存于当前浏览器 `lishui-itinerary-v2`，兼容迁移旧收藏；“清空行程”移除个人安排。复制包含来源、导航与待确认项；自动复制受限时，使用“查看行程文字”手动全选复制。没有账号同步、订单履约或图片/打印导出。

新增验证：`npm run test:itinerary`（9组）。[场景与验收报告](docs/旗舰任务场景与结构化行程验收_2026-10-04.md)包含两份真实查询设计样例、证据范围和待开展的访谈模板；这不等于真实游客试用或单/多智能体效果对比。
