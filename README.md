## 10. 一日结构化行程（2026-10-04）

打开 `/itinerary`，或从首页选择两条任务草案。先填日期、起终点、同行人数、交通和预算；每个地点点击“查地点”并从候选中选用实际入口/店铺/展馆，再填自己的停留和费用估计，点击“查询路线并重算时间”。时间冲突、超预算、交通未知和未核开放条件会列在核对区。移动/移除或更换交通后按需重新查询；超过24小时的估时不参与计算。地图不保证出行日班次或预约。

行程存于当前浏览器 `lishui-itinerary-v2`，兼容迁移旧收藏；“清空行程”移除个人安排。复制包含来源、导航与待确认项；自动复制受限时，使用“查看行程文字”手动全选复制。没有账号同步、订单履约或图片/打印导出。

新增验证：`npm run test:itinerary`（9组）。[场景与验收报告](docs/旗舰任务场景与结构化行程验收_2026-10-04.md)包含两份真实查询设计样例、证据范围和待开展的访谈模板；这不等于真实游客试用或单/多智能体效果对比。

## 11. 主打节点访前指南与知识深化（2026-10-04）

天生桥、无想山、傅家边、石臼湖详情页各有5个可展开问题；资料讲解与个人规划建议分开，门票、开放、班次、花果情况等按出行日期再确认。新版指南复用实际获审QA，完整问题在后端直返相同正文；措辞变化或新约束仍走RAG/服务查询。

`npm run test:content`为5组隔离回归；`npm run check:content`需当前API/本机凭据/网络，检查7组真实检索、互斥过滤及6组HTTP（含RAG变体）。四节点矩阵、资料访问边界和截图见[本轮验收](docs/主打节点知识深化与验收_2026-10-04.md)。版权问题按用户确认跳过；R05剩余4条待核、童谣及专题深度继续维护。

## 12. 专家路由、实际状态与对照评测（2026-10-04）

问答通过 `/api/chat/stream` 接收真实任务状态，再显示完整答复；可停止、重试，部分失败保留其他答复。跨节点分别检索、分别引用；固定已审问题仍优先本地答复。没有模拟百分比。新版静态状态及四种路径见[路由与状态验收](docs/专家路由与协作状态验收_2026-10-04.md)。

`npm run test:routing`为10组隔离回归；`npm run check:routing`在当前真实API检查15组知识/服务/跨节点。`npm run eval:rag`会发生真实供应商调用，重建30题各3次的单角色/多角色及12题无知识库分支，完整输出在本地忽略目录 `docs/evaluation`。查看既有汇总运行 `node scripts/summarize-evaluation.mjs`。当前216次试验是受控规则基线，不能直接宣称通用多智能体优势；人工语义评分仍待完成。详见[评测方法与结果](docs/RAG与协作受控评测_2026-10-04.md)。
