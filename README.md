## 本地启动

需要Node20或更高版本。

```powershell
npm ci
npm run build
npm run dev
```

`npm run dev`同时启动Vite127.0.0.1:5173及API127.0.0.1:8787；需根据`config/integrations.env.example`配置本机`config/integrations.env.local`。只看页面用`npm run dev:web`，离线完整流程用下述离线包。真实密钥只放服务端环境文件，不能用VITE_变量或放public。

本地默认显示正式新版，不显示设计对比栏。需要回看旧版时，手动打开 `/design-preview?designReview=1` 启用本地对比工具；生产版始终关闭该工具。

```powershell
npm run demo:offline:build
npm run demo:offline:serve
```

离线资料页默认127.0.0.1:4493，可阅读资料、已审固定问答、文化小任务和行程编辑/导出；开放RAG、实时地图/天气/住宿/翻译未连接，外部出处及导航仍需联网。已验证的新ZIP见运行包入口，完整解压后`node start.mjs`。

## 知识与接口

127条已审QA全部归淮源姐，29风物与8类服务保留；待核/撤下资料继续隔离。本批未修改已审问答正文或向量索引。更新语料后需运行`node scripts/export-reviewed-corpus.mjs`与`npm run rag:index`，再重启API。访客答复展示简洁正文，来源和审核依据在答案下“协作说明”中按需展开。

`/api/guide`注册一个向导，`/api/chat`返回当前答复，`/api/chat/stream`发出真实任务进度及正文delta；停止会取消请求。常见已审问题直接回答，开放检索只用相关证据，未找到时明确未知，并提示公告或现场核对路径。`trace.agentId`记录后台专家；所有答复的`speaker`仍为淮源姐。来源分为已审知识检索、实际返回的实时工具、联网待核和译文；未使用网页与失败查询不被当作成功证据。

## 协作演示

进入 `/guide`，点击示例“周末两天、两个人、想看骆山大龙”。天气、住宿和文化任务先并行处理；路线沿用现有依赖顺序，在住宿任务结束后执行；最后由行程规划师汇总。前台显示真实进度与“待补条件/未完成”，由淮源姐给出一条答复。

“周末”不自动换算成已确认日期：天气可能先查默认当天并明确标注；住宿缺入住/退房日期时不调用供应商。已给“两个人”不再追问人数。缺出发地只定位目的地，不宣称已取得完整路线。演出日期、当期活动和场地开放待核，不以传统时段代替当年安排。补齐日期、出发地和每晚预算，再查询报价与路线；结果仍以平台和主办方确认信息为准。

打开答案下“协作说明”核对实际专家、任务状态与来源。六位功能专家共享语料与规则、非独立人格；原关于页已由账号入口替代。协作改造历史详见 [验收记录](reports/persona-collaboration-2026-10-07.md)。

对话只存在当前页面内存，站内导航连续，刷新/新对话结束；后端不建聊天数据库。个人行程先存当前浏览器，登录后可主动保存到账号、跨设备载入。设备本地中文声音用于主动朗读，自然音色接入仍待实施。

## 账号配置

只使用 Supabase 项目 `zsz370's Lishui`。按 `config/accounts.env.example` 配置服务端私有文件 `config/accounts.env.local`，不使用 `VITE_` 变量、service_role 或前端密钥。生产 `ACCOUNT_COOKIE_SECURE=true`；本机 HTTP 联调可设为 false。

新项目执行 `supabase/migrations/202610070001_itinerary_cards.sql` 一次，已存在表时先核查策略；`supabase/tests/itinerary_cards_rls.sql` 在事务中验证归属隔离并回滚测试数据。行程表启用强制 RLS，仅登录用户可读写自己的卡片，无永久删除权限。最多保留50张卡（包含回收站）；更新已有卡不增加数量。

按用户要求关闭 Authentication → Sign In / Providers → Confirm email。邮箱只作为登录名，不验证归属，不做验证码或邮件确认，无需 SMTP。Site URL 与唯一 Redirect URL 为 `https://lsguide.cn/login`。注册成功即登录，访问会话最多1小时，不在前端保存令牌、不发刷新令牌；过期请重新登录。未提供密码找回流程。

行程页“保存到账号”是主动上传，编辑不会自动覆盖云端。账号页可载入、移到回收站、恢复；多页同时保存发生版本冲突时需重新载入。访客和各账号的本机行程草稿分开；账号切换或过期会清理当前对话，云端不存对话。
